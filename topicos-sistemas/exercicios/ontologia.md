# Trabalho de Ontologia

## Criar Ontologia (classes)

Escolha um domínio e crie uma ontologia no Protégé, considerando apenas a definição de classes, subclasses  em uma hierarquia taxonômica.

Envie o arquivo com a extensão owl, rdf ou owx.

## Criar ontologia (propriedades)

Considerando a ontologia criada na tarefa anterior, adicione propriedades para definir as relações entre as classes (domain/range) e propriedades para os atributos (literal).

Use o Tutorial da Pizza para te ajudar nessas definições.

## Criar ontologia (instâncias)

Uma das alternativas para conferir a ontologia é a inserção dos dados. Diante disso, insira as instâncias para cada classe criada, bem como as propriedades. Use o reasoner para conferir sua ontologia.
