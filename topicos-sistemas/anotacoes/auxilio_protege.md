# Atalhos e Instruções de Uso da Ferramenta

## Etapa 1

Criar classes com todos os dados que serão representados, incluindo as sub-classes. Utilizar atalho ```CTRL + E``` para ir criando as classes/sub-classes.

## Etapa 2

```Ctrl + SPACE``` -> completa o texto sendo digitado.  
Executar o **Reasoner** para verificar se não houveram tribuições incorretas que volem as regras de funcionamento. Utilizar o atalho ```CTRL + R``` e o _plug-in_ ***Pallet***.

## Etapa 3

Colocar dados reais para as rerpresentações de classes, atributos, instâncias. Utilizar a opção **Individuals by class** (aba) para inserir os valores reias a serem utilizados, seja nas classes ou sub-classes. Depois utilizar as relações criadas e os valores inseridos e criar as relações entre cada etapa através da opção **Object Properties**, por exemplo: ```pertenceAoGenero → AcaoGenero```.  
Depois inserir os dados das instâncias com as informações já inseridas através da opção **Data Properties**, por exemplo: ```plataforma → "Arcade"```.  
Executar o **Reasoner** para verificar se não houveram tribuições incorretas que volem as regras de funcionamento. Utilizar o atalho ```CTRL + R``` e o _plug-in_ ***Pallet***.
